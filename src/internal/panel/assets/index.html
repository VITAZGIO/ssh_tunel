Устройства

У каждого устройства свой ключ и своя системная учётная запись на сервере — панель заводит и удаляет их сама, без консоли.

Добавить устройство

Выбери, на чём стоит программа, и придумай имя, по которому потом узнаешь это устройство в списке. Сразу после создания панель один раз покажет готовые настройки вместе с ключом: для телефона — QR-кодом, для компьютера — кнопкой «Скопировать» или файлом.

Ключ клиента готов

Это единственный раз, когда панель показывает приватный ключ сам, без нажатия «Показать настройки» в списке. Сохрани его сейчас — он понадобится, чтобы подключить устройство.

Нажми на код, чтобы открыть во весь экран — так его проще отсканировать телефоном.

Сеть устройств

Твои устройства в одной сети через твои же серверы — как NetBird: каждое получает постоянный адрес и имя вида «ноутбук.mesh».

Роль этого сервера

Серверов может быть несколько: один главный, остальные подключаются к нему. Устройства, подключённые к любому из них, окажутся в одной сети.

Прямые соединения: прогноз

Проверка NAT идёт сама при каждом подключении устройства. По её итогам — смогут ли устройства когда-нибудь соединяться напрямую, минуя сервер.

Серверы сети

Код готов. Он содержит ключ доступа — передай его только на свой сервер. Один код — для одного сервера: для следующего получи новый.
  1. Открой панель побочного сервера → «Сеть устройств».
  2. Выбери «Побочный сервер» и вставь код.
  3. Нажми «Подключить к главному» — через несколько секунд сервер появится здесь на схеме.

Автозапуск

Включено — панель поднимется сама после перезагрузки сервера. Снятая галочка не выключает панель прямо сейчас, а только не даёт ей стартовать в следующий раз.

Панель запущена не через systemd — управлять автозапуском отсюда нечем.
