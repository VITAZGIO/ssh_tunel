# Иконка приложения

Сейчас в приложении стоит **геральдический щит** с фактурой логотипа:
`../icon-source.svg` → `../icon-source.png` → `../icon.ico` → в exe.

## Фактура

Взята один в один с логотипа VG. Приём такой: `feTurbulence` даёт фрактальный
шум (частота 1.6, четыре октавы, зерно 5), а `feColorMatrix` **выбрасывает
собственный цвет шума** и подставляет вместо него одну постоянную краску,
почти чёрную с синевой. Шум после этого управляет только прозрачностью этой
краски, поэтому щит нигде не уходит в посторонний оттенок — он просто местами
темнеет.

Замер по отрисованному PNG: красный канал 39…45 (почти не гуляет), зелёный
75…226, синий 89…255. То есть зерно меняет яркость, а не тон. Средний тон по
щиту — `#2aa4bb`, приглушённый бирюзовый; в самых светлых точках светит чистый
циан `#2de2ff`. Выглядит как пескоструйный металл цвета морской волны.

Скважина чёрная, а не сквозная: сквозную на тёмной панели задач не видно.
Фон прозрачный.

## Перерисовать иконку

Формы правятся в `../icon-source.svg`, после чего SVG надо растрировать в PNG
512×512 с прозрачным фоном. Шум `feTurbulence` считает браузерный движок,
поэтому нужен Chromium или Edge:

```bash
chrome --headless --screenshot=icon.png --window-size=700,700 \
       --default-background-color=00000000 page-with-svg.html
```

Окно берётся с запасом и снимок обрезается до 512×512: при окне ровно
512×512 нижняя часть картинки в снимок не попадает.

Дальше — обычным путём:

```bash
go run tools/mkicon/main.go internal/nativeui/icon-source.png internal/nativeui/icon.ico
./build.sh
```

## Запасные силуэты

Плоские варианты без фактуры, нарисованные `tools/mkshield` (все с острыми
углами, сквозной скважиной и прозрачным фоном):

| Файл | Силуэт |
|---|---|
| `1-pyatiugolnyy-512.png` | пятиугольный значок |
| `2-treugolnyy-512.png` | треугольный |
| `3-geraldicheskiy-512.png` | геральдический (его форма и взята за основу) |
| `4-so-skosom-512.png` | со скошенными верхними углами |
| `5-normannskiy-512.png` | норманнский, бока с изломом |
| `6-vognutyy-512.png` | вогнутые бока |

Поставить любой из них: скопировать в `../icon-source.png` и пересобрать.
