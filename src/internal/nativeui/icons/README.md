# Заготовки иконки приложения

Щиты в цвет логотипа со сквозной замочной скважиной. Углы острые, скруглений
в контуре нет. Прозрачный фон. Рисуются инструментом `tools/mkshield`.

| Файл | Силуэт |
|---|---|
| `1-pyatiugolnyy-512.png` | пятиугольный значок: прямые плечи, две грани к острию |
| `2-treugolnyy-512.png` | треугольный: плоский верх, прямые грани в остриё |
| `3-geraldicheskiy-512.png` | классический геральдический: прямые плечи, выпуклые бока |
| `4-so-skosom-512.png` | со скошенными верхними углами |
| `5-normannskiy-512.png` | норманнский: бока с изломом, длинное остриё |
| `6-vognutyy-512.png` | вогнутые бока, узкое остриё |

Сейчас в приложении стоит вариант 1.

## Поменять иконку

```bash
cp internal/nativeui/icons/3-geraldicheskiy-512.png internal/nativeui/icon-source.png
./build.sh
```

`build.sh` соберёт из этого файла `.ico` во всех размерах (16…256) и вошьёт
его в exe вместе с манифестом.

## Поменять сами формы

Силуэты заданы многоугольниками в `tools/mkshield/main.go` — правится там,
затем:

```bash
go run tools/mkshield/main.go internal/nativeui/icons
```
