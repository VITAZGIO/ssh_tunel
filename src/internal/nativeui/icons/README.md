# Заготовки иконки приложения

Варианты щита в цвет логотипа, нарисованные `tools/mkshield`. Прозрачный фон.

| Файл | Что это |
|---|---|
| `1-skvazhina-512.png` | сплошной щит, замочная скважина вырезана насквозь |
| `2-zamok-512.png` | сплошной щит, навесной замок вырезан насквозь |
| `3-kontur-skvazhina-512.png` | контур щита, скважина внутри |
| `4-kontur-zamok-512.png` | контур щита, замок внутри |
| `5-gradient-512.png` | сплошной щит с градиентом, скважина вырезана |
| `6-dvoynoy-512.png` | щит с внутренней окантовкой, скважина вырезана |

Чтобы поменять иконку приложения — скопируй нужный файл в
`internal/nativeui/icon-source.png` и запусти `./build.sh`: он пересоберёт
`.ico` во всех размерах и вошьёт его в exe.

Пересобрать сами варианты (например, подкрутив формы):

```bash
go run tools/mkshield/main.go internal/nativeui/icons
```
