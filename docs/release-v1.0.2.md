## ssh_tunel 1.0.2

Исправление: после сохранения настроек трафик шёл мимо туннеля.

### Что было не так

Окно настроек отправляло программе только те поля, которые видны на экране.
Переключателей системного прокси и переменных среды там нет — и при каждом
нажатии «Сохранить» они молча выключались.

Снаружи всё выглядело исправно: кнопка зелёная, «Защищено», каналы SSH
подключены, тест скорости показывал реальные цифры через сервер. А браузер при
этом продолжал ходить напрямую, со своим обычным адресом.

Проявлялось на любом компьютере, где настройки задавали через окно — то есть
почти у всех. Обходной путь для 1.0.1: полностью выйти из программы через
значок у часов и запустить заново, не нажимая «Сохранить».

Теперь отсутствующее в запросе поле означает «не трогай», а не «выключи».
Добавлен тест, который это проверяет.

### Что скачивать

| Система | Файл |
|---|---|
| Windows 10 / 11 | `ssh_tunel.exe` |
| Linux (обычные серверы) | `ssh_tunel-linux` |
| Linux ARM (Raspberry Pi и подобное) | `ssh_tunel-linux-arm64` |

Обновление: заменить файл. Настройки сохранятся.

После обновления зайди в настройки и нажми «Сохранить» ещё раз — это вернёт
выключенные переключатели на место. Проверить можно на любом сайте, который
показывает твой IP: он должен совпадать с адресом сервера.
