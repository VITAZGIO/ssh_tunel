## ssh_tunnel 1.1.0

Программа переименована в **ssh_tunnel**, и исправлена ошибка, из-за которой
трафик мог идти мимо туннеля.

### Важное исправление

Окно настроек отправляло программе только те поля, которые видны на экране.
Переключателей системного прокси и переменных среды там нет — и при каждом
нажатии «Сохранить» они молча выключались.

Снаружи всё выглядело исправно: кнопка зелёная, «Защищено», каналы SSH
подключены, тест скорости показывал реальные цифры через сервер. А браузер при
этом продолжал ходить напрямую, со своим обычным адресом. Проявлялось на любом
компьютере, где настройки задавали через окно.

Теперь отсутствующее в запросе поле означает «не трогай», а не «выключи».

### Новое имя

Файлы называются `ssh_tunnel.exe`, `ssh_tunnel-linux`, `ssh_tunnel-linux-arm64`.
Настройки переезжают сами — из папок прежних имён, ничего переносить руками не
надо. Адрес репозитория остаётся прежним.

### Пользователь только для туннеля

По умолчанию программа теперь подключается пользователем `tunnel`, а не `root`.
Смысл: ключ, который лежит на компьютере, не должен открывать весь сервер. Такой
пользователь умеет ровно одно — пробрасывать соединения; ни выполнить команду, ни
забрать файл им нельзя.

Подсказка у поля «Приватный ключ» переписана: вместо одной команды теперь три
шага — создать ключ, показать его, добавить на сервере под `root`. Одной командой
это больше не делается именно потому, что пользователю туннеля запрещено
выполнять команды. Третья команда заодно создаёт такого пользователя, если его
ещё нет.

Как настроить сервер с нуля — в [SERVER-SETUP.md](https://github.com/VITAZGIO/ssh_tunel/blob/main/docs/SERVER-SETUP.md).

### Кнопка «Проверить сеть»

В настройках, у поля «Всегда напрямую». Смотрит сетевые адаптеры компьютера и
говорит по каждой найденной сети, останется ли она доступной при включённом
туннеле. Нашлись проблемные — добавляет их в список одним нажатием.

Спрашивать адреса офисной сети у человека бессмысленно: он их обычно не знает.
Зато их знает его компьютер.

### Мелочи

- Длинные пояснения в настройках убраны под знаки вопроса — экран стал чище.
- Значок у часов больше не показывает старое имя программы.

### Что скачивать

| Система | Файл |
|---|---|
| Windows 10 / 11 | `ssh_tunnel.exe` |
| Linux (обычные серверы) | `ssh_tunnel-linux` |
| Linux ARM (Raspberry Pi и подобное) | `ssh_tunnel-linux-arm64` |

Обновление: удалить старый `ssh_tunel.exe`, положить новый. Настройки
сохранятся. После первого запуска зайди в настройки и нажми «Сохранить» — это
вернёт на место переключатели, выключенные прошлой версией.
